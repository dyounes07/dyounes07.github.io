Transaction Fraud Detection

Machine learning

An end-to-end fraud detector trained on 284,807 real card transactions, where only 0.17% are fraud. A model that calls everything legitimate scores 99.8% accuracy and catches nothing, so I evaluated with precision, recall, and PR-AUC instead.

I compared a logistic regression baseline with XGBoost, then served the XGBoost model through a Flask API that validates input and lets each request set its own risk threshold. On held-out data it caught 84% of fraud with 92% precision. It's been my favourite project!!

  • scikit-learn

Quadratic Field Cryptography

Cryptography research

Research on Diffie–Hellman in the class groups of imaginary quadratic fields. We represented group elements as binary quadratic forms and showed in SageMath that multiplying them is fast, while reversing it (the discrete log problem) stays hard.
